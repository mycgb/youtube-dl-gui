# YouTube 视频下载器（解析 + 音视频合成）

一个带图形界面的 YouTube 视频下载工具。核心解析逻辑逆向自 `youtube.iiilab.com` 的前端接口，支持 144p ~ 4K 多档清晰度，并能把 YouTube 分离的**纯视频流**和**纯音频流**合成为一个带声音的视频文件。

## 功能

- 粘贴 YouTube 链接即可解析，支持普通视频、Shorts、youtu.be 短链
- 显示标题、作者、时长、封面预览，列出所有可用清晰度
- **视频 + 音频合成**：下载无声音视频流与音频流，用 ffmpeg 合成单一文件。视频流直接复制不重编码，速度快、画质无损
- 仅下载视频（无声音）
- 下载音频并转换为 MP3
- 下载视频封面
- 快速下载 360p（站点提供的已混流地址，不需要 ffmpeg）
- 断点续传、实时进度/速度、取消任务
- 直链失效（403/404）自动重新解析并重试
- 代理配置（系统代理 / 不使用 / 自定义），可一键测试连接
- 输出目录、代理、ffmpeg 路径自动保存到配置文件，无需每次重设

## 运行环境

- Windows（其他平台理论上可用，需自行调整启动脚本）
- Python 3.8+，安装时需勾选 **tcl/tk / tkinter**
- ffmpeg：用于音视频合成和 MP3 转换。按以下顺序自动查找：
  1. 环境变量 `FFMPEG_PATH`
  2. PATH 中的 `ffmpeg`
  3. 已安装的 `imageio-ffmpeg`（`pip install imageio-ffmpeg`）
  4. 常见安装目录（`C:\ffmpeg\bin\ffmpeg.exe` 等）
  5. 界面中手动指定

封面预览需要 Pillow（`pip install pillow`），没有也能正常下载视频，只是不显示缩略图。除此之外**仅依赖 Python 标准库**。

## 使用方法

### 启动

双击 `启动下载器.bat`，或：

```bash
python youtube_dl_gui.py
```

> 启动脚本中默认使用 `D:\Python\python.exe`，如你的 Python 在别处，请修改该文件中的路径。

### 下载步骤

1. 在输入框粘贴 YouTube 视频链接，点 **解析视频**（或按回车）
2. 在清晰度列表中选择一行（默认选中 720p；双击行可直接合成下载）
3. 根据需要点击功能按钮：

| 按钮 | 说明 |
|---|---|
| **视频+音频合成** | 下载选中清晰度的视频流 + 音频流，合成一个带声音的文件（推荐） |
| 仅下载视频 | 只有画面，没有声音 |
| 下载音频(MP3) | 下载音频流并转成 MP3 |
| 下载封面 | 保存视频缩略图 JPG |
| 快速下载 360p(含声音) | 使用站点已混流的 360p 地址，无需 ffmpeg，速度最快 |

### 设置

- **输出目录**：下载文件保存位置。点击「浏览」选择，改动会自动保存
- **网络代理**：
  - `系统代理`：跟随系统/环境变量设置
  - `不使用代理`：直连
  - `自定义`：填写 `http://127.0.0.1:7890` 这类地址。工具启动时会探测本机常见的代理端口（7890 / 10809 / 1080）并自动填入
  - 点「测试连接」可验证当前代理能否访问 YouTube 和解析接口
- **ffmpeg**：合成所需的程序路径，一般会自动找到，也可手动选择

所有设置保存在脚本同目录的 `youtube_dl_config.json`，下次启动自动读取。该文件含本机路径，已加入 `.gitignore`，不会入库。

### 菜单

- **文件**：选择/打开输出目录、退出
- **工具**：检查 ffmpeg、清理未完成的 `.part` 临时文件
- **帮助**：使用说明

## 实现原理简述

解析接口为 `POST https://webapi.iiilab.com/api/web/extract`，请求体为 `{"url": ..., "site": "youtube"}`，需要两个自定义头：

- `G-Timestamp`：当前 Unix 秒级时间戳
- `G-Footer`：`md5(url + site + 时间戳 + 签名密钥)`

密钥从站点前端 JS bundle 中提取。接口返回的 `variants[]` 中，高清晰度为无声音的纯视频流（DASH），同时给出对应的独立音频流；工具将两者分别下载后用 ffmpeg 合成：

```
ffmpeg -i video.mp4 -i audio.m4a -map 0:v:0 -map 1:a:0 \
       -c:v copy -c:a aac -movflags +faststart output.mp4
```

WebM/VP9 视频则直接 `-c copy` 保留 VP9 + Opus。视频流不重编码，因此合成几乎不耗时。

## 常见问题

**解析失败 / 提示网络错误**
点「测试连接」检查代理。国内网络通常需要配置可用的代理，且系统代理不一定能访问 googlevideo.com，可尝试 `http://127.0.0.1:7890`。

**提示下载 403 / 直链失效**
YouTube 直链签名有效期有限，工具会自动重新解析并重试（最多 3 轮）。若仍失败，手动点一次「解析视频」再下载。

**下载很慢 / 看起来卡住**
144p/360p 通常几 MB，4K 可能超过 300 MB。默认选中 720p，可在列表中改选更小的清晰度。进度会实时显示百分比与速度，中断后再次点击同一按钮会从 `.part` 文件续传。

**合成后视频没有声音 / 时长变短**
工具会校验合成结果的音视频流和时长。若音频流下载不完整，日志会给出警告；删除临时文件后可重新解析再试。也可改用「快速下载 360p(含声音)」绕过合成。

**找不到 ffmpeg**
按上面的「运行环境」章节安装，或在界面中手动指定 `ffmpeg.exe` 完整路径。

## 注意事项

- 请仅下载你有权保存的内容，遵守 YouTube 服务条款与当地版权法规。
- 签名算法来自第三方网站前端，站点更新后可能失效，届时接口调用会失败，需要重新逆向。
- 项目仅供个人学习与技术交流使用。
